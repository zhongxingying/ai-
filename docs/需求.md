# 智能办卡 Agent 工作台 · 需求文档

## 1. 这个项目是什么
一个能自己完成办卡全流程的 AI 数字员工。
不是"问一句答一句"的客服，而是能自己查套餐、比价、推荐、确认、下单。

## 2. 谁用
- 普通用户：注册、看套餐、下单、查订单、找 Agent 咨询
- 管理员：管套餐、处理工单、看 Agent 运行记录

## 3. 核心功能
### 用户能做的
1. 注册 / 登录
2. 看套餐列表
3. 办卡下单（选套餐 → 填地址 → 确认 → 下单）
4. 跟 Agent 聊天（查套餐、查订单、下单、投诉）
5. 看我的订单
6. 提工单 / 看工单进度
7. 问知识库（比如"销户怎么办"）

### 管理员能做的
1. 套餐增删改查
2. 处理工单
3. 看 Agent 运行记录（每步 Thought / Action / Observation）

## 4. 不做什么（划边界）
- 不做真实支付
- 不做真实短信验证
- 不做多租户
- 不做移动端 App

## 5. 成功标准
- 用户能完整走通：注册 → 登录 → 问 Agent → 下单 → 查订单
- Agent 能自己调用至少 5 个工具
- Agent 每一步能追踪、能复现
- 最后能上线一个能演示的地址

## 6. 非功能需求
- HTTPS
- 接口限流
- 日志带 trace_id
- /health 健康检查
- Agent 可观测（每步可查）
- Agent 失败能降级（降级到单轮 RAG 问答）
